浏览器网页会话连接

支持 ChatGPT（普通聊天与项目内会话）、Codex Web 和 DeepSeek Web。Chrome / Edge 安装独立扩展后，网页消息会进入统一收件箱，手机端回复可转发到对应网页标签。

1
加载浏览器扩展

电脑打开 chrome://extensions（Edge 用 edge://extensions），开启「开发者模式」→「加载已解压的扩展程序」，选择项目的 extensions/browser 文件夹。

2
复制连接配置

点击复制，在浏览器工具栏打开「AttnWall Web Bridge」，粘贴并点击连接。

3
打开具体会话并保持标签运行

ChatGPT ↗、Codex Web ↗ 或 DeepSeek Web ↗。进入具体任务或对话，首次抓取的历史会静默导入。

浏览器标签必须保持打开，网页关闭时无法继续读取或发送。扩展不读取站点 Cookie / API Key。连接配置含专用密钥，请勿公开。网页升级导致输入框变化时，转发可能需要重新适配。

连接说明

本机默认连接器会扫描 Codex 会话。DSH 使用 SDK 接入已知会话 ID，运行时必须已安装。其他电脑可独立启动 Connector 并连接到同一个消息中心。

添加 Agent 会话

选择会话来源。不同平台的连接流程相互独立，不需要为网页会话填写 DSH Session ID。

DeepSeek Harness · DSH

已有会话请填写原始 ID；不填写则创建新的持久会话。
